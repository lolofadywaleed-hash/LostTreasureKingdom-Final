# Lost Treasure Kingdom

مشروع مغامرات ثلاثي الأبعاد مبني على Godot 4.3، ويبدأ بشاشة اختيار الأبطال ثم ينتقل إلى نموذج لعب أولي بمنظور خلفي.

## التشغيل
افتح `project.godot` في Godot 4.3 أو أحدث. اختر لولو أو السيد أو فادي. على الحاسوب: الحركة عبر WASD/الأسهم والقفز عبر Space (تضاف تعريفات الإدخال تلقائياً في إعدادات المشروع/يلزم ضبطها في Input Map). على الهاتف: اسحب في الجهة اليسرى للتحرك واضغط زر القفز.

## Android
ملف `.github/workflows/build.yml` يتحقق من المشروع ويصدر APK تجريبياً عند تحديث `main` أو يدوياً من GitHub Actions. يلزم ضبط Android SDK وJava 17 في runner. ملف APK الناتج debug/test وليس إصدار متجر.

## صور الشخصيات
لم تكن الصور المشار إليها مرفقة في مساحة العمل المتاحة وقت التنفيذ؛ البطاقات حالياً مؤقتة وملونة. ضع الصور في `assets/heroes/` لتضمينها لاحقاً.
